# 问题反馈

如果您在安装、运行或配置 SmartDNS Edge 的过程中遇到了 Bug，或有任何好的功能建议，欢迎在下方填写表单。

您的反馈会**先提交给维护者审阅**，确认后才会公开到 **[GitHub Issues](https://github.com/Gdxz-Linus/smartdns-edge/issues)** 中。这样既能保证公开区的讨论质量，也能避免无关内容打扰其他使用者。

- 提交后您会看到「已收到」的提示，**不会立刻出现 Issue 编号**——因为内容此时还在审阅阶段；
- 如果反馈需要跟进，我们可能会通过您留下的联系方式回复；
- 请**不要**在正文中包含 `api-token`、私钥等敏感信息。
